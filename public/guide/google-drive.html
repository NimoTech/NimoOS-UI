Connect Google Drive (using your own Google credentials)

Follow the steps below to create a set of authorization credentials under your own Google account, then enter them into NimoOS to connect your Google Drive. Takes about 10 minutes, and it's free.

Why create your own? This way the authorization uses your own Google app — access stays strictly between you and your device, and never passes through any shared third-party account. More private, and more stable. You only need to create the credentials once.

Before you start

  • A Google account (the one that owns the Drive you want to connect).
  • It's easiest on a desktop browser.

  1. Create a Google Cloud project

    Open console.cloud.google.com and sign in. Click the project dropdown at the top → New Project, any name (e.g. NimoOS) → after it's created, switch to that project.

  2. Enable the Google Drive API

    In the left menu APIs & Services → Library, search for Google Drive API, open it → Enable.

  3. Configure the OAuth consent screen (“Google Auth Platform”)

    Left menu APIs & Services → OAuth consent screen. The current UI opens “Google Auth Platform” as a short wizard — fill it step by step:

    • App Information: app name (e.g. NimoOS) + a user support email → Next;
    • Audience: choose External → Next;
    • Contact Information: developer contact email — use your own email (this app is entirely yours; nothing here is NimoOS's) → Next;
    • Finish: agree, then Create.

    After creating, set two more things from the left menu:

    • Data Access → Add scope:
    Scope to addhttps://www.googleapis.com/auth/drive
    • Audience → “Test users” → add your own Google email address.
    You must add a test user! Otherwise Google will reject the authorization (access_denied). Note: the developer contact email is on the wizard's “Contact Information” step, not the first screen.

  4. Create an OAuth client ID

    Left menu Clients → Create client (older UI: APIs & Services → Credentials → Create Credentials → OAuth client ID):

    • Application type: Web application;
    • Under “Authorized redirect URIs”, add this line (exactly):
    Authorized redirect URIhttps://cloudoauth.nimopc.com

    Click Create.

    This URI must match exactly (no trailing slash, no spaces), or authorization will fail with redirect_uri_mismatch.

  5. Copy the client ID and secret

    After creation, the Client ID and Client secret are shown. Copy both (the secret is only shown here, so save it now).

  6. Back in NimoOS, enter them and authorize

    In NimoOS, choose Connect Google Drive, paste the Client ID and Client secret from the previous step, then click authorize.

    After being redirected to Google, sign in with your account and approve; you'll be sent back to NimoOS automatically.

    If you see “Google hasn't verified this app”, that's expected — because this is the app you just created. Click “Advanced” → “Go to … (unsafe)” to continue; it is safe for your own app.

Troubleshooting

Authorization rejected with access_denied?

Go back to “Test users” in Step 3 and make sure the Google email you're using has been added.

Getting redirect_uri_mismatch?

The redirect URI in Step 4 is wrong. It must be https://cloudoauth.nimopc.com — no trailing slash or spaces.

Disconnects after about a week and asks to re-authorize?

This happens while the app is in “Testing” status (tokens expire in ~7 days). For long-term use, set the app's publishing status to “In production” back in Step 3 — you'll still see the “unverified” prompt (just click continue), but tokens will no longer expire every 7 days.

Is this safe? Could my files leak?

Yes, it's safe. The credentials live under your own account and only authorize your own NimoOS device; files transfer directly between your device and Google, never through any third-party server.

NimoOS · 连接云盘

连接 Google Drive(使用你自己的 Google 凭据)

按下面的步骤,在你自己的 Google 账号下创建一组授权凭据,再填进 NimoOS,就能把 Google Drive 接入你的设备。全程约 10 分钟,无需付费。

为什么要自己创建? 这样授权用的是你自己的 Google 应用,权限只在你和你的设备之间,不经过任何第三方共享账号,更私密、也更稳定。凭据只需创建一次。

开始前

  • 一个 Google 账号(就是你要连接的那个 Drive 所属的账号)。
  • 用电脑浏览器操作更顺手。

  1. 新建一个 Google Cloud 项目

    打开 console.cloud.google.com 并登录。点顶部的项目下拉菜单 → 新建项目,名字随意(如 NimoOS)→ 创建后切换到该项目。

  2. 启用 Google Drive API

    左侧菜单 API 和服务 → 库,搜索 Google Drive API,点进去 → 启用。

  3. 配置 OAuth 同意屏幕(“Google Auth Platform”)

    左侧 API 和服务 → OAuth 同意屏幕。当前新版会打开 “Google Auth Platform” 分步向导,逐步填:

    • 应用信息:应用名称(如 NimoOS)+ 用户支持邮箱 → 下一步;
    • 受众群体:选 外部(External) → 下一步;
    • 联系信息:开发者联系邮箱 —— 填你自己的邮箱(这个应用完全是你自己的,与 NimoOS 无关)→ 下一步;
    • 完成:勾选同意 → 创建。

    创建后,再从左侧菜单配置两处:

    • 数据访问 → 添加范围(Scope):
    要添加的权限范围https://www.googleapis.com/auth/drive
    • 目标对象(受众群体) → “测试用户 (Test users)” → 把你自己的 Google 邮箱加进去。
    务必添加测试用户! 不加的话授权会被 Google 拒绝(access_denied)。注意:开发者联系邮箱在向导的“联系信息”那一步,不在第一屏。

  4. 创建 OAuth 客户端 ID

    左侧 客户端(Clients) → 创建客户端(旧版界面:API 和服务 → 凭据 → 创建凭据 → OAuth 客户端 ID):

    • 应用类型选 Web 应用(Web application);
    • 在“已获授权的重定向 URI”里,添加下面这一条(一字不差):
    已获授权的重定向 URIhttps://cloudoauth.nimopc.com

    点 创建。

    这条地址必须完全一致(结尾不要多斜杠、不要空格),否则授权会报 redirect_uri_mismatch。

  5. 复制客户端 ID 和密钥

    创建成功后会弹出 客户端 ID 和 客户端密钥。把这两串复制下来(客户端密钥只在这里能看到,建议先存好)。

  6. 回到 NimoOS 填入并授权

    在 NimoOS 里选择连接 Google Drive,把上一步的 客户端 ID 和 客户端密钥 填进去,然后点授权。

    跳转到 Google 后,用你的账号登录并同意授权即可,授权完成会自动跳回 NimoOS。

    授权时若看到 “Google 尚未验证此应用” 的提示,这是正常的 —— 因为这是你自己刚创建的应用。点 “高级 / Advanced” → “继续前往(不安全)” 即可,对你自己的应用是安全的。

常见问题

授权被拒,提示 access_denied?

回到第 3 步的“测试用户”,确认已把你正在用的这个 Google 邮箱加进去了。

提示 redirect_uri_mismatch?

第 4 步的重定向 URI 没填对。必须是 https://cloudoauth.nimopc.com,结尾不能多斜杠或空格。

连过一阵子(约一周)后又断了、要重新授权?

这是应用处于“测试”状态的特性(令牌约 7 天过期)。想长期稳定使用,可到第 3 步那里把应用的发布状态改为“正式版 / In production”——授权时仍会有“未验证”提示(点“继续”即可),但令牌不再每 7 天过期。

这样安全吗?会不会泄露我的文件?

安全。凭据是你自己账号下的,只授权给你自己的 NimoOS 设备;文件在你的设备和 Google 之间直接传输,不经过任何第三方服务器。

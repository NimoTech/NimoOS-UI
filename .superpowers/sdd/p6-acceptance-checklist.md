## 0. 开始之前(读完这 5 条再动手,否则会报一串假缺陷)

### 0.1 🔴 这一期必须在 **80 端口**验,不能起 dev server

本期验的是**绞杀**(strangler)—— 「从 Vue2 老应用点一下,应该落到 New-UI 新应用」。
这是**跨应用**行为:起点在 Vue2(挂 `/`),终点在 New-UI(挂 `/app/`)。
dev server 时期两个应用各占一个端口、互相看不见,**根本验不了**。

⇒ **浏览器只开这一个地址**:`http://192.168.1.143/`
(SP9-P8 就是因为拿 dev 端口跑 cutover 清单,机主验出 6 条假缺陷。)

### 0.2 两个入口地址,记清楚

| 你想到哪 | 地址 |
|---|---|
| **Vue2 老桌面**(绞杀的起点;`/` 本身已被绞杀到新桌面,所以要走 `/legacy`) | `http://192.168.1.143/#/legacy` |
| **New-UI 新桌面** | `http://192.168.1.143/app/#/` |

### 0.3 怎么设/清那把回退开关(B 节要用)

两个应用**同源同端口**,共用同一份 `localStorage` —— 这正是必须在 80 端口验的原因之一。
浏览器按 `F12` 打开开发者工具 → `Console`(控制台)→ 粘贴回车:

```js
// 置为回退(AI 区退回 Vue2 老页面)
localStorage.setItem('strangler:disabled:/ai', '1')
// 清除(恢复 cutover,回到新应用)
localStorage.removeItem('strangler:disabled:/ai')
// 查当前值('1' = 回退中;null = cutover 生效中)
localStorage.getItem('strangler:disabled:/ai')
```

🔴 **改完 flag 之后不要只按刷新** —— 要**回到起点重新点一次**(回 `#/legacy` 桌面、或重新在地址栏敲一次 AI 地址)。
理由:开关是在「**你点下去那一刻**」读的,不是页面加载时读的。你人已经在 AI 页里了,设了开关也不会把你踢出来。

### 0.4 🔴 回退开关**只挡入口,不拆路由**(这不是缺陷)

置 `'1'` 之后,New-UI 的 `/app/#/ai/*` 那些路由**仍然注册着**。
也就是说:**书签、历史记录、地址栏直接敲 `http://192.168.1.143/app/#/ai/agent`,照样能进新 AI 页。**
被挡住的只有「从入口点进去」这条路(Vue2 地址栏 `/#/ai/*`、New-UI 桌面磁贴/小组件/搜索面板)。
这是设计如此(回退是给「新页面出问题、让用户走回老路」用的,不是权限开关)。**看到这个不要报缺陷。**

## 一、⛔ 破坏面判定(读 Go 源码 + curl 实测,开工前定死)

### 1. `POST /v1/sys/migrate` —— 破坏性极高,本期一次都不发

`NimoOS/service/migrate.go` 逐段读过:

| 阶段 | 动作 | 源码行 |
|---|---|---|
| 停服务 | `docker ps -q` → `systemctl stop docker.socket docker containerd` → `pkill -9 -f containerd-shim`;photos 类型还先停 `nimoos-photos` | `:454-484` |
| 预检 | statfs 目标盘,需 `size + 5% + 1GiB` | `:280-299` |
| 拷贝 | `rsync -a --one-file-system` 到 `<dst>.migrating` 暂存 | `:597-660` |
| 换锚点 | `rename anchor→anchor.bak` + `symlink dst→anchor`,全部成功后 **`os.RemoveAll` 删掉旧数据** | `:777-820` |
| 收尾 | 写 `/var/lib/nimoos/path_config.json` + 重启 docker | `:823-828` |

## 七点五、过程事故与教训

1. **⚠️ 实现者跑了 `git reset`**(Task 3 期间,reflog `HEAD@{1}` "reset: moving to HEAD"),把索引里那 3 个 `design-export/*` staged 删除退成 unstaged。HEAD 未变、未被卷进任何 commit。控制器尝试 `git add` 复位**被权限分类器拦下**,交用户处置。此后所有派发提示词明令禁止 `git reset`。**教训:禁令清单里光写 checkout/stash/add -A 不够,`reset` 也要写。**
2. **计划书的中文文案有 4 处标点写成了半角**(Vue2 是全角 `，` `！`),Task 4 评审做字节级比对才逮到;Task 8 的测试断言里还残留 2 处,实现者自己发现。**教训:文案不能靠转写,要用脚本从 `zh_CN.json` 直接取。**
3. **「就地过期守卫 + 交错测试」这条通用要求被我套用过度**:StoragePanel 只在挂载时取一次数、没有第二个触发点,实现者为凑交错测试给页面**加了一个 Vue2 没有的刷新按钮**。已撤回,守卫改成 `alive` 布尔,并按变异验证结论删掉了那条空转用例。**教训:通用要求要先问"这个组件真有这条路径吗"。**
4. **四次「用例空转」被评审逮到**(Task 2 两次、Task 3 一次、Task 9 一次遗留 minor):共同点是**排序/兜底/jsdom 特性把缺陷掩盖了**,变异不翻红。**教训:每条用例都要问"把它覆盖的那行改坏会不会翻红",不确定就真做一次变异验证。**
5. **补写路径测试顺带逮到一个真 bug**:`v-for` 里的字符串 `ref` 被 Vue 收集成数组,重命名输入框 `.focus()` 失效。**这正是"会动用户数据的路径必须有测试"的价值证明。**

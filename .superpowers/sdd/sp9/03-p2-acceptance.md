## 已知的、不用报给我的

- **「切换到混合模式」看不到** —— 债务 **D19**(本机 config 里没有 wifi 口 → 后端不算 `hybridCapable`)。同理 concurrent 的「Wi-Fi / 热点」双 tab 界面在本机也进不去,只有单测覆盖。
- **看不到「虚拟网络」那种行**(docker0 / br-* / veth* / zt*)—— 后端 `/v1/sys/utilization` 的 net 只给物理口,这些永远不会出现。代码里那段判定照旧 UI 移植并有单测,只是本机不可达(同 D19)。
- **弹窗标题从「Wi-Fi - x」改成按类型派生** —— 你 2026-07-31 拍板的(授权偏离 #7)。
- **中文界面里「连接 / 以太网 / 虚拟网络 / 未找到网络接口 / 已断开连接 …」现在有中文了** —— 旧 UI 这 9 处**所有 31 个语言文件都缺译**,一直显示英文原文;你拍板补译(授权偏离 #8)。
- **保存成功后没有「4 秒后再刷一次」的行为** —— 旧 UI 用 4×2s 轮询补抓 DHCP 地址,新版列表本来就 5 秒一刷,那段轮询删掉了(旧 UI 那个定时器还漏了卸载停表)。

## 附:这一期改了哪些"旧 UI 的 bug"(移植纪律登记,共 8 处)

界面严格 1:1,但旧 UI 的 bug / 竞态 / 吞错不照抄 —— 每处都在代码里写了注释:

1. **高级设置里填的 DNS 会被静默丢弃**(旧 UI 的两个子表单各自持有一份 `dnsString`,改了从不回写父层,而保存用的是父层那份)→ 统一由弹窗持有,单测 + 变异验证钉死
2. 保存后那段 4×2s 补抓定时器**不随面板卸载停表** → 整段删掉,由 5 秒实时流替代
3. **裸切模式失败了还是照样打开配置弹窗**(用户以为切成功了)→ 失败就报错且**不开弹窗**
4. `scanWifi` 的早退分支不复位 `scanning`、复位不在 `finally` 里 → 改 `try/finally`
5. 弹窗标题**恒为 `Wi-Fi - <网卡名>`** → 按类型派生(你拍板)
6. 两个声明了、算了、传了但**模板零使用**的 prop(`clientConnected` / `clientIpInfo`,而且类型还是错的)→ 不移植
7. 扫描列表 `:key="net.ssid"` 在**同名/隐藏 SSID** 时 key 重复(实测扫描结果里真有一条 ssid 是 `00:00:00:00:00:00`)→ key 用 `bssid || ssid`
8. 弹窗里的失败提示用 toast(z-index 60,被 z-index 1000 + 毛玻璃的遮罩压住 + 糊掉)→ 改成弹窗内联红字,并优先显示后端原文

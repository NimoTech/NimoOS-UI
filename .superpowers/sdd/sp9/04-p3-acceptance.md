## ⛔ 这一期有三个地方**请不要点**

这不是谨慎过度,三条我都读了后端源码/实测过:

### 1. 「Docker 缓存清理」的「清理」按钮(确认框里那个)

后端是 `ContainersPrune(空过滤器)` + `ImagesPrune(空过滤器)`(`NimoOS-AppManagement/service/container.go:902`)——**会删掉这台机器上全部已停止的容器**。我查了当前状态,会被删的正是你桌面上那两个小组件:

```
nimoos-demo-widget    exited   ← 会被删
todo-widget           exited   ← 会被删
```

外加 1 个 1.94GB 的悬空镜像。运行中的 5 个容器(phoenix / agent / photos-ml 等)不受影响,build cache 也不在删除范围。

**点开确认框看一眼没问题,但请点「取消」。** 你 2026-08-01 拍板不点 → 债务 **D23**。

### 2. 迁移弹窗里的「开始迁移」

`POST /v1/sys/migrate` 会:停 docker + 全部容器 → rsync 搬数据 → 换锚点软链 → **删掉旧数据**(`NimoOS/service/migrate.go:454/597/777-820`)。

不过**这条在本机走不通**:这台机器只有一个分区(`/dev/nvme0n1p7` 挂 `/`),弹窗第一步会直接显示「没有其他可用的存储」、「下一步」是灰的。所以你**想点也点不到**——这也是它成为债务 **D22** 的原因(要等有多盘设备才能验)。

### 3. 迁移弹窗浏览步骤里的新建 / 重命名 / 删除文件夹

会真的动 `/DATA` 下的目录。同样因为第 1 步走不通,实际到不了。

> 这三条的正确性目前由 **18 例弹窗单测 + 9 例面板单测 + 多次变异验证**兜着(改坏任何一条都会翻红),但**没有真跑过**。

## 附:这一期改了哪些「旧 UI 的 bug」(移植纪律登记)

界面严格 1:1,但旧 UI 的 bug / 竞态 / 吞错不照抄 —— 每处都在代码里写了注释:

1. **日志用 `v-html` 渲染** —— 旧 UI 把服务端日志原文当 HTML 塞进页面(日志里含文件名/路径等可控内容时是注入面)→ 改成纯文本渲染,**看起来一模一样**。
2. **日志末尾少一个字符** —— 旧 UI 的 `substring(8, 长度-1)` 把整块日志的最后一个字符也吃掉了(off-by-one)→ 只裁开头。
3. **切走页面后日志还在偷偷轮询** —— 旧 UI 的 5 秒定时器只在切 tab 时清,组件直接销毁时会漏 → 改成卸载即停。
4. **迁移进度轮询失败后会无限重试** —— 旧 UI 的 catch 只打印到控制台;真机上 job 丢失时后端返回 HTTP 400「job not found」,它会一直轮下去 → 改成连续失败 5 次停表并显示后端原文。
5. **迁移完成后写三个没人读的 localStorage 键** —— 全仓 grep 过没有任何读取方 → 不移植。
6. **写死的 970GB 容量兜底** —— 旧 UI 找 `mount_point` 里含 `ZimaOS-HD` 的分区当默认容量(挂载点永远不含这个字符串,是 CasaOS 血统的卷标名),失败就写死 970GB → 改成回退系统卷真实容量。
7. **路径归属判断没有目录边界** —— 会把 `/media/BackupOld` 判成属于 `/media/Backup`(纯字符串前缀)→ 改成按路径分段判断(本仓 `snapshotPath.ts` 早有同样的修正)。
8. **重命名输入框点了不自动聚焦** —— `v-for` 里的字符串 ref 被 Vue 收集成数组,`.focus()` 调用无效 → 改成函数 ref。(这条是补写路径测试时顺带发现的真 bug。)

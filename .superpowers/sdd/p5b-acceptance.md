# 🔴 先读这个:哪些"看起来不对"的地方其实是对的

这一批的纪律是**界面 1:1 照抄 Vue2**,所以下面这些**都不是缺陷**,别浪费时间截图:

## 一、Vue2 语言包自身的错译,照抄不改(9 处)

| 你会看到 | 为什么 |
|---|---|
| 表头「**类型**」出现**两次** | Vue2 把 `Action`(操作)和 `Type`(类型)都译成「类型」,撞车了 |
| 「恢复」按钮 | Vue2 把 `Rebuild`(重建)译成「恢复」 |
| 分页「**上一张 / 下一步**」 | Vue2 把 `Previous`/`Next` 译成了这两个词 |
| 状态筛选里的「**已启用**」 | Vue2 把 `Active` 译成「已启用」 |
| 「累计完成」出现两次、「向量数」出现两次 | Vue2 语言包里本来就是同一个值 |

要改这些是**独立的产品决策**(得同时改 Vue2 和新 UI 两边),不能夹在迁移里顺手做。

## 三、其它预期行为

- **空态里那个「清空筛选」按钮是没有样式的裸按钮** —— Vue2 就长这样(它的模板引用了一个 Vue2 自己没定义的 CSS 类)
- **「索引中」状态的徽标文字显示英文 `Indexing`** —— Vue2 语言包里本来就没这条中文,回落成英文原串
- **行内详情面板展开时没有淡入动画** —— Vue2 的动画名写错了(引用了一个不存在的动画),照抄
- **颜色与 Vue2 不是像素级相同** —— Vue2 用的是 iOS 系统色(如 `#34C759` 绿),这里按主题规范全换成了 NimoOS 的色板,存在**刻意的**色相偏移。结构、渐变角度、透明度层级都没变
- **概览页那个 60 秒才消失的骨架屏照旧不修**(上一批就定了不修)

## 四、🔴 会真的写数据的操作,别乱点

- **「恢复」/「重建选中」/「重建该 Root 全部」** —— 都会给文件**打墓碑并重新入队**。本机已经有 338 个待处理任务,点了会更多。只想看界面就别点。
- **「清空失败记录」** —— 真删。本机失败桶是空的所以按钮禁用,别为了点它去造数据。
